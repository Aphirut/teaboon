# ระบบเทียบโอนผลการเรียน สกร. 2567

โปรแกรมคำนวณและเทียบโอนผลการเรียนตามหลักสูตรส่งเสริมการเรียนรู้เพื่อคุณวุฒิ สกร. พ.ศ. 2567

## ความต้องการของระบบ

- Node.js 20 ขึ้นไป (ทดสอบด้วย Node.js 26)
- ไม่ต้องใช้คีย์ API ก็เปิดใช้งานได้ ระบบจะทำงานในโหมดจำลองผลวิเคราะห์ (Simulation)

## เริ่มใช้งาน

1. ติดตั้งไลบรารี (ต้องทำก่อนเปิดระบบครั้งแรก)

   ```
   npm install
   ```

2. เปิดเซิร์ฟเวอร์สำหรับพัฒนา

   ```
   npm run dev
   ```

3. เปิดเบราว์เซอร์ที่ http://localhost:3000

## การตั้งค่าคีย์ AI (ไม่บังคับ)

หากต้องการใช้ผลวิเคราะห์จากโมเดลจริง ให้สร้างไฟล์ `.env.local` ที่โฟลเดอร์หลักของโปรเจกต์

```
TYPHOON_API_KEY=คีย์ของท่าน
```

ตัวแปรที่รองรับ

| ตัวแปร | ใช้กับ |
| --- | --- |
| `TYPHOON_API_KEY` | Typhoon OCR (อ่านรูป/PDF ใบระเบียน) และ Typhoon 2.5 (สกัดรายวิชา วิเคราะห์ เขียนสรุป) |
| `OPENROUTER_API_KEY` | ตัวช่วยตัดสินใจ (Decisions) ในแท็บจับคู่วิชา |

ถ้าไม่ตั้งคีย์ ระบบจะแจ้งบนหน้าจอว่าใช้โหมดจำลอง และยังคำนวณเทียบโอนได้ครบทุกขั้นตอน

## ตัวช่วยตัดสินใจ (Decisions) แล้วให้ Typhoon เขียนบันทึก

ในแท็บ "จับคู่วิชาหลักสูตร 2567" มีการ์ด **ตัวช่วยตัดสินใจ** ทำงานสองขั้นตอน

1. ส่งข้อความบริบทของเคสไปที่ `POST /api/decisions/analyze` ซึ่งเรียก OpenRouter Decisions (`/api/alpha/decisions`) พร้อมชุดคำถามตามเกณฑ์ (`noul`, `choice`, `score`) แล้วได้คำตอบกลับมาเป็นค่าที่ตัดสินแล้ว
2. ส่งคำตอบชุดนั้นพร้อมบริบทของเคสให้ Typhoon เรียบเรียงเป็นบันทึกความเห็นภาษาไทย (หัวเรื่อง สรุป ข้อเสนอแนะ ขั้นตอนถัดไป)

ปรับแก้ชุดคำถามได้ที่ `src/data/decisionQuestions.ts` และกำหนดค่าปลายทางได้ด้วยตัวแปร

| ตัวแปร | ค่าเริ่มต้น |
| --- | --- |
| `OPENROUTER_DECISIONS_URL` | `https://openrouter.ai/api/alpha/decisions` |
| `OPENROUTER_DECISIONS_MODEL` | `perplexity/pplx-decider-v1.1-27b` |
| `TYPHOON_MODEL` | `typhoon-v2.5-30b-a3b-instruct` |

## ใช้งานจริง (Production)

```
npm run build
npm start
```

บน Windows ให้ตั้งค่าตัวแปรก่อนเริ่มเซิร์ฟเวอร์

```
$env:NODE_ENV='production'; npm start
```
